# Creative Producer popup onboarding

Use `ask_user`. Put the recommended choice first and suffix its label with ` (Recommended)`. Ask one question at a time unless up to three answers naturally belong together. Every question needs 2–4 selectable options; free text is supplied automatically, so never add an Other option. For specific card titles, asset paths, or provider names, tell the operator to type them in the free-text response.

## 1. Run scope

Ask: **What should I produce this run?**

- **Produce every eligible card in Design / Video Production (Recommended)** — every card whose `Draft status: complete` and `Creative status: queued` matches the contract.
- **Produce one selected card** — the operator types the card title or short link in free text.
- **Re-render one selected card** — operator types the card name or the local asset path in free text.
- **Cancel this run**.

## 2. Render strategy

Ask: **Which render strategy should I use?**

- **AI generation only** — call `image_generate` or `video_generate` for the whole asset. Best for unique illustration, scenes, or people.
- **Deterministic HTML/CSS template only (Recommended for text-heavy posts)** — render via the contract template (default `templates/lead-magnet-card.html` + Playwright). Reproducible, no AI flakiness, surfaces layout bugs deterministically.
- **AI background + HTML/CSS overlay** — generate the background with the model, then composite the deterministic template on top. Text is never generated by the model.

## 3. Regeneration budget

Ask: **Regeneration budget?**

- **2 attempts (Recommended)** — switch to the deterministic fallback after two failures.
- **3 attempts** — same fallback rule, more attempts allowed.
- **Unlimited (cost warning)** — never auto-fallback; ask the operator on each repeated failure.

## 4. Image policy override

Ask only when the contract pins `single_image_only: true` and any selected card still has `Format: carousel`.

Ask: **Image policy override?**

- **Downgrade to single image (Recommended)** — per contract policy.
- **Force carousel anyway** — override for this card; record the override in the asset log.

## 5. Provider / model

Ask only when a card’s `Creative brief` lacks a confirmed provider/model.

Ask: **Which provider/model should I use for this card?** — the operator types `provider/model` (e.g., `openai/gpt-image-2`) in free text. The agent never picks a provider on its own.

## 6. Run plan confirmation

Show the full plan in chat: scope, eligible cards, render strategy, regeneration budget, image policy overrides, providers/models. Then ask:

- **Use this plan (Recommended)**
- **Change answers**
- **Cancel run**

## 7. Per-asset decision

After generating every asset, ask:

- **Save and route (Recommended)**
- **Regenerate with different prompt**
- **Switch to deterministic template**
- **Skip this card**
- **Pause and inspect manually**

Do not write to Trello until the operator chooses `Save and route` for each asset.
